## 🚀 Deployment to GitHub Pages

1. **Initialize & Commit Code**:
   ```bash
   git add .
   git commit -m "Initial commit: Crescent National Academy official school website"
   ```

2. **Add Remote GitHub Repository**:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_GITHUB_USERNAME/crescent-national-academy.git
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - Go to your GitHub repository **Settings** -> **Pages**.
   - Under **Build and deployment**, set **Source** to `Deploy from a branch`.
   - Select `main` branch and `/ (root)` folder, then click **Save**.
   - Your live site will be published at `https://YOUR_GITHUB_USERNAME.github.io/crescent-national-academy/`.
